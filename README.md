# PicNickTreeRuns

PicNickTreeRuns is a DreamBot Farming script by PicNick for standard tree and fruit tree runs.

![PicNickTreeRuns](assets/picnicktreeruns-200.png)

## Public Release

- **Current public release:** v0.20
- **Jar:** eleases/PicNickTreeRuns-DreamBot-Public.jar
- **DreamBot script name:** PicNickTreeRuns
- **DreamBot script module:** PicNickScripts
- **SDN Parameters:** PicNickTreeRuns
- **Java compatibility:** Java 8 bytecode.
- **QuickStart:** No
- **Ironman supported:** Yes, where account supplies and requirements allow.

## Source And SDN

This public repository intentionally ships the compiled release jar, documentation, icon asset, submission notes, and checksum only. The proprietary source is not distributed here.

DreamBot SDN submission uses the repository/module fields provided in the DreamBot Scripter Panel. Use the private DreamBot-hosted source repository/module for SDN compile, not this public GitHub repository.
