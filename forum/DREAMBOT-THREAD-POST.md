# PicNickTreeRuns

PicNickTreeRuns is a Farming tree-run script by PicNick.

## Features

- Simple and Advanced setup modes.
- Standard tree and fruit tree route planning.
- Ironman supply/sapling preparation knowledge.
- OSRS-chatbox-style overlay with settings, Discord, report bug, and hide controls.
- Local sanitized bug reports and runtime diagnostics.

DreamBot SDN submission is pending/manual; this public repository does not contain proprietary source code.
