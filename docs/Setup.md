# Setup

1. Start on any safe world/location.
2. If the account is on a free world, the script attempts a bounded safe hop to a members world.
3. If members access/hopping fails, the script stops and logs the reason before any Farming route actions.
4. The script resolves the closest bank and validates tools/materials before route actions.
5. Configure Simple or Advanced mode.
6. Settings save under the PicNickTreeRuns data profile for the next boot.
