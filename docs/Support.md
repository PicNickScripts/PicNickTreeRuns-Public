## Discord

Use the PicNick support Discord invite:

[https://discord.gg/83GnaxbGC](https://discord.gg/83GnaxbGC)

Post PicNickTreeRuns issues in the bug report channel for this script.

## Overlay Report Bug Flow

1. Run PicNickTreeRuns until the issue happens.
2. Click Report Bug on the overlay.
3. The script generates a sanitized DreamBot-safe report.
4. Review the popup text.
5. Paste the report into the Discord bug report channel.

## What To Include

- What mode was selected: Simple or Advanced.
- Whether the account is Ironman.
- What patch or transport step was active.
- The sanitized report text from the overlay.
- A short note about what you expected the script to do.

Do not paste passwords, account credentials, Discord webhooks, or private local files.
